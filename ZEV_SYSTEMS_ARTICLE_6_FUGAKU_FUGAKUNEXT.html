Introduction

Fugaku is Japan’s flagship at RIKEN-RCCS (Kobe): Fujitsu A64FX, HBM2, 415 PF HPL. FugakuNEXT follows: Kobe 2029, ops 2030; next-gen GPUs, Fujitsu Monaka-X, colocated IBM quantum. This article covers both: scale, node, FugakuNEXT architecture, performance targets, storage, and strawman node vision.

Fugaku (R-CCS)

Dec 04, 2024 · #system/japan.

RIKEN-RCCS Kobe. Fujitsu A64FX, HBM2. HPL 415.53 PFLOPS (June 2020 Top500).

[Image: Fugaku — system / cabinets]
R-CCS Kobe

Scale: 158,976 nodes, 158,976 A64FX (1 per node), 432 racks (396 full @ 384 nodes, 36 half @ 192). Platform: 2 nodes/CMU, 8 CMUs/BoB, 3 BoBs/shelf, 8 shelves/rack. Commercial: PRIMEHPC FX1000. Node: 1× A64FX (48 SVE + 2 assist, 2.0–2.2 GHz, 3.07–3.38 TF FP64); 32 GB HBM2, 1024 GB/s; 1× 10-port Tofu D (28 Gbps×2); 1× PCIe Gen3 x16.

FugakuNEXT (R-CCS)

Aug 22, 2025 · #system/japan.

Follow-on flagship; RIKEN-led, Fujitsu design, GPU vendor TBD. Kobe 2029, operations 2030.

[Image: FugakuNEXT — announcement / diagram]
Specs or site

Scale: Over 3,400 nodes, 15K GPUs. 2.6 EF FP64; 20× over Fugaku, 60× over K; 600 EF FP8 2:1 sparse. <40 MW (30 MW target). Architecture: Fujitsu Monaka-X (ARM, SME, possible NPU); Next-gen GPU; TBD host–device coherent; NVLink scale-up; custom scale-out. Colocated 156-qubit IBM Heron on scale-out fabric.

Performance targets and requirements

Satoshi Matsuoka (Salishan 2025): raw 10×–20×; mixed precision 2×–8×; surrogates/PINN 10×–25×; total 200×–1000× over Fugaku (“Zettascale”).

[Image: Performance targets / requirements table]
RFP table or slide

System requirements (RFP / vendor): FP64 vector CPU 48 PF / GPU 3,000 PF; FP16/BF16 matrix CPU 1,500 PF / GPU 150,000 PF; FP8 CPU 3,000 PF / GPU 300,000 PF; FP8 2:1 sparse GPU 600,000 PF; memory 10 PiB CPU / 10 PiB GPU; bandwidth 8 PB/s CPU / 800 PB/s GPU.

Storage and strawman vision

Storage (FugakuNEXT): Tier 1 near-node (e.g. CHFS, BeeOND); Tier 2 shared (Lustre, DAOS).

Strawman non-quantum node (2028–2030): 3D-stacked CPU + accelerator; >20 TB/s SRAM (to ~40 TB/s); CGRA strong-scaling accelerator, >1 PF/node; silicon photonics 12 Tbps (1 Tbps×12); ~80k nodes; 2–3 EB/s mem BW (15–25× Fugaku); ~100 EF low-precision; 30×–100× app over Fugaku; ~30 MW. Themes: 3D stack, silicon photonics, CGRA, PIM.

Why Fugaku and FugakuNEXT matter

Fugaku: 158k A64FX, 432 racks, Arm SVE, HBM2, Tofu D — reference for all-CPU Arm exascale. FugakuNEXT: 3.4k+ nodes, 15K GPUs, 2.6 EF FP64, 600 EF FP8 sparse, Monaka-X + next-gen GPU, IBM Heron 156q, 30 MW; 200×–1000× target; strawman 80k nodes, 3D stack, silicon photonics, CGRA. Reference for Japan’s flagship CPU+GPU+quantum roadmap.
