### Top LinkedIn Frameworks & Templates

#### 1. Justin Welsh's Hook → Value → Engagement Framework
```
HOOK (Line 1):
- Contrarian statement
- Bold claim
- Problem statement
- "Most people [wrong belief]. Here's why..."

VALUE (Lines 2-10):
- Specific framework
- Step-by-step process
- Real example/case study
- Actionable insight

ENGAGEMENT (End):
- Specific question (not "What do you think?")
- "What's your biggest challenge with [topic]?"
- "What's been your experience with [topic]?"
```

#### 2. Dan Koe's Authority Framework
```
Line 1: Hook (problem or insight)
Lines 2-4: Context (why this matters)
Lines 5-10: Deep value (framework, system, process)
Line 11: Question (invite discussion)
```

#### 3. Dickie Bush's Story Framework
```
1. Setup (the situation)
2. Struggle (the problem)
3. Solution (what worked)
4. Success (the result)
5. Lesson (what you learned)
```

#### 4. Matt Gray's Viral Post Structure
```
Hook: Bold statement or contrarian take
Context: Why this matters to your audience
Value: Framework, insight, or actionable tip
Proof: Results, case study, or example
CTA: Question or call to action
```

#### 5. Lara Acosta's Engagement Framework
```
- Start with a hook that creates curiosity
- Share a personal story or case study
- Provide actionable value (framework/template)
- End with a question that invites discussion
- Use line breaks for readability
```

### Top Viral Post Templates

#### Template 1: The Framework Post
