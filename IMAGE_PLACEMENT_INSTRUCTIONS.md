## Image Editing Tips:

1. Use any image editor (Photoshop, Canva, etc.)
2. Crop out the profile picture/avatar area
3. Remove or blur the creator's name
4. Keep the tweet text clear and readable
5. Keep all engagement metrics visible
6. Maintain the tweet's visual style (dark background, white text)
7. Save as PNG format for best quality
