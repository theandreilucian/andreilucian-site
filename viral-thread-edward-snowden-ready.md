SEARCH STRATEGY:
1. Go to Unsplash.com or Pexels.com
2. Use search terms provided for each tweet
3. Filter: Free to use commercially
4. Download high resolution (at least 1920px wide)
5. Edit in Canva if needed

VIDEO STRATEGY:
1. Use Pexels Videos for stock footage
2. Use YouTube thumbnails (fair use)
3. Create graphics in Canva and export as video
4. Add text overlays in Canva

- Image size: 1200x675px (16:9) or 1200x1200px (square)
- Video: Max 2:20, 1080p recommended
- File size: Max 5MB (images), 512MB (videos)
