Carousel 1 · 0 → 15K (8 slides)

LinkedIn Lesson I Used To Go 0 → 15K

“Use a boring rhythm long enough for the graph to bend — not a viral lottery.”

Andrei Lucian@theandreilucian

The math

~15K follows · 730 days

Average ≈ 625 new followers / month — looks boring until it compounds.

I didn’t blow up. I shipped outputs + comments until strangers started associating my name with one problem.

Next: patience →

Andrei Lucian@theandreilucian

Timeline

Year 1 felt slow. Year 2 felt unfair (in my favor).

Most of the felt lift came when I stopped refreshing the graph daily.

The win wasn’t one post — it was one theme for long enough to become familiar.

Next: 3 metrics →

Andrei Lucian@theandreilucian

Inputs I control

3 metrics I tracked

Follower count alone is a lagging indicator.

  • Posts shipped / week (published, not “almost”)
  • 10–20 min / day of real comments in the right threads
  • Qualified DMs / month (specifics, not spam)

Next: what I stopped →

Andrei Lucian@theandreilucian

Subtraction

I stopped doing these 3 things

This bought me months back.

  • Treating LinkedIn like TikTok (trend-chasing on a text platform)
  • Borrowing someone else’s voice to post faster
  • Hitting publish, then ghosting my own comments

Next: what I doubled down on →

Andrei Lucian@theandreilucian

The engine

I doubled down on these 3 things

Unsexy — until your inbox agrees.

  • One boss topic for long stretches (tighter over time)
  • Proof in public — numbers, frameworks, real mistakes
  • Threads that go somewhere — replies that add value

Next: if you’re still “small” →

Andrei Lucian@theandreilucian

Proof window

If your follower count still looks small…

You’re not “early.” You’re in the window where credibility is decided.

Run a clean 90-day sprint: niche + post + comment — then judge the line.

Niche + luck matter. This behavior still compounds.

Carousel 2 · If I restarted from 0 (7 slides)

If I Restarted LinkedIn At Zero Tomorrow

“Run a 7 / 30 / 90 sequence — not motivation, not hacks.”

Andrei Lucian@theandreilucian

Days 1–7

Fix the profile like a landing page

Cap prep at 7 days — after that you’re hiding.

  • Headline: who you help + outcome + hint of proof
  • About: problem → how you think → what to do next
  • Featured: 2–3 receipts (post, doc, case bite)

Next: first 30 days →

Andrei Lucian@theandreilucian

Days 8–30

12 posts · daily comments

Reps reveal your real voice — not “inspiration.”

  • 12 posts in 30 days (~3/week)
  • Each post = 1 claim + 1 proof beat + 1 takeaway
  • 10–15 min/day of comments that advance the thread

Next: days 31–90 →

Andrei Lucian@theandreilucian

Days 31–90

3 bets I’d make

This is where “random poster” becomes a brand.

  • One problem I want my name tied to — repeat it
  • DMs: fast replies when someone brings specifics
  • ~1 save-worthy asset / 2 weeks (carousel, checklist)

Next: traps →

Andrei Lucian@theandreilucian

Hygiene

3 traps I’d never touch again

Short-term spikes. Long-term reputational debt.

  • Pods + empty “support” loops
  • Copying someone’s sentences, not just structure
  • Daily posting with zero thesis (busy ≠ credible)

Next: unfair advantage →

Andrei Lucian@theandreilucian

Moat

The unfair advantage: document real work

You already have content — you’re not shipping it.

Meetings fixed. Mistakes caught. Frameworks rebuilt.

Authenticity isn’t a vibe. It’s evidence.

Carousel 3 · 16 lessons (7 slides)

16 Lessons From 2 Years On LinkedIn

“Save this and re-read on day 70 when you want to quit.”

Andrei Lucian@theandreilucian

Lessons 1–4

Clarity + distribution

Small audience is a feature — if you’re precise.

  • 1. First ~500 followers = jury, not applause.
  • 2. One sharp problem beats ten vague headline “areas.”
  • 3. Comments beat hashtag tricks — daily leverage.
  • 4. One specific DM beats 50 lazy “great post” DMs.

Next: 5–8 →

Andrei Lucian@theandreilucian

Lessons 5–8

Trust + hygiene

Your profile argues for you — silently.

  • 5. Empty Featured = “trust me” with no receipts.
  • 6. First line is a promise — break it, lose the save.
  • 7. 3 weak posts/week can cost more than 2 strong ones.
  • 8. Pods rot signal — behave like you’d defend it.

Next: 9–12 →

Andrei Lucian@theandreilucian

Lessons 9–12

Proof people can feel

Humans hire humans.

  • 9. Post what you already solve at work — skip the persona.
  • 10. Real numbers get saved. Adjectives don’t.
  • 11. Reply in ~60 min when you can — early depth compounds.
  • 12. Real life + weekends can unlock disproportionate inbound.

Next: 13–16 →

Andrei Lucian@theandreilucian

Lessons 13–16

Patience + POV

The part people skip — then regret.

  • 13. ~90 days feels flat — then it bends.
  • 14. Virality = lottery. Consistency = skill.
  • 15. POV filters — that’s how you find the right room.
  • 16. Brand = proof, repeated. One hit ≠ reputation.

Next: 3 rules →

Andrei Lucian@theandreilucian

Non-negotiables

Only 3 rules I’d enforce forever

Everything else is commentary.

  • 1) One boss topic long enough to be remembered
  • 2) Comments + DMs with specifics
  • 3) Ship on the calendar — not on mood

Carousel 4 · The “secret” (6 slides)

The LinkedIn “Secret” Is Boring

“You’ll ignore it — until reply speed + specificity compounds.”

Andrei Lucian@theandreilucian

Secret #1

Comments = leveraged networking

10–20 minutes/day changes perception.

One thoughtful comment beats 50 lazy likes.

Write like you’re adding value in a meeting — not clapping from the back row.

Next: saves →

Andrei Lucian@theandreilucian

Secret #2

Likes are vanity — saves are intent

Give people a reason to come back.

  • A checklist
  • A framework
  • One real number + what it means

Next: POV →

Andrei Lucian@theandreilucian

Secret #3

Be predictable on purpose

People follow what they can remember.

Pick one boss problem. Say it often. Prove it often.

You’re becoming easy to refer — not “narrow.”

Next: 60-minute loop →

Andrei Lucian@theandreilucian

System

My weekly 60-minute loop

Busy people: start here.

  • 20 min — finish 1 post people can use
  • 20 min — 8–12 sharp comments (quality > count)
  • 20 min — DMs: follow-ups + specifics + next step
