# Quick Guide: Compress Yanina Video

## Option 1: Tell Me Where FFmpeg Is

1. Find where you extracted/downloaded FFmpeg
2. Look for `ffmpeg.exe` - it's usually in a `bin` folder
3. Copy the full path (example: `C:\ffmpeg\bin\ffmpeg.exe`)
4. Tell me the path and I'll compress it for you!

## Option 2: Run the Script Yourself

1. Open PowerShell in the `D:\Website` folder
2. Run: `powershell -ExecutionPolicy Bypass -File compress-yanina-now.ps1`
3. When it asks for FFmpeg path, paste the full path to `ffmpeg.exe`
4. Wait for compression to finish

## Option 3: Use the Batch File

1. Edit `compress-yanina-video.bat`
2. Change the FFmpeg path on line 26 to your FFmpeg location
3. Double-click the `.bat` file

## Option 4: Use Online Tool (Easiest!)

1. Go to: https://www.freeconvert.com/video-compressor
2. Upload: `D:\Website\assets\images\video testimonial\Yanina - Ghostwriter.mp4`
3. Compress it (choose "High Compression" or target 15-20 MB)
4. Download the compressed file
5. Replace the original with the compressed one
