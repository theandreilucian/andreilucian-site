The X System — Landing → Gumroad automation
============================================

YOUR FLOW (fully automated after setup)
---------------------------------------

  1. Visitor lands on YOUR site:
     https://andreilucian.com/0-to-1K-X-System/LANDING.html

  2. Clicks any "Get Instant Access" button
     → Redirects to YOUR Gumroad product page (payment + delivery)

  3. Gumroad charges the buyer (card / PayPal)

  4. Gumroad emails the buyer automatically:
     • Receipt
     • Andrei Lucian - The X System.zip download link

  5. Buyer unzips → opens OPEN-FIRST.html or INDEX.html → starts Day 1

  YOU do not need:
  • Stripe on your website
  • Password gates or unlock codes on your site
  • Manual email sending
  • A separate checkout page (optional CHECKOUT.html only redirects to Gumroad)


ONE-TIME SETUP CHECKLIST
------------------------

□ Build ZIP:  node scripts/build_product_zip.mjs
              → 0-to-1K-X-System/downloads/Andrei Lucian - The X System.zip

□ Gumroad → Products → New product
  • Name: The X System
  • Price: $47 (one-time USD)
  • Description: copy from GUMROAD-SALES-PAGE.html
  • Cover image: assets/images/x-growth-system-playbook-cover.png
  • Content tab → Upload: Andrei Lucian - The X System.zip
  • Leave "email customers" ON (Gumroad handles delivery)

□ Gumroad → Share → copy link (andreilucian.gumroad.com/l/xxxxx)

□ Paste link in: 0-to-1K-X-System/product-checkout.js
     gumroadProductUrl: "https://andreilucian.gumroad.com/l/YOUR_REAL_SLUG"

□ Push to GitHub (Vercel deploys landing automatically)

□ Test: LANDING → buy on Gumroad → confirm ZIP email arrives

HOW BUTTONS ON THE LANDING PAGE WORK
------------------------------------
  • All buttons use href="CHECKOUT.html" in the HTML
  • landing.js reads product-checkout.js and rewrites them to your Gumroad URL
  • directCheckout: true  → buyers skip your site checkout (go straight to Gumroad)
  • Until you paste a real Gumroad link, buttons go to CHECKOUT.html (setup reminder)

---------------------------------
  node scripts/build_product_zip.mjs
  Gumroad → Products → The X System → Content → replace Andrei Lucian - The X System.zip
