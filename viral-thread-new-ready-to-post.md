   - Free images and videos
   - Search: "technology", "privacy", "business"

FREE VIDEO SOURCES:
1. Pexels Videos
   - Search: "office", "technology", "business"
   - Download free stock videos

2. YouTube (for thumbnails)
   - Search relevant topics
   - Use video thumbnails (fair use for thumbnails)
   - Or create your own video

3. Canva Video
   - Create simple animated graphics
   - Free templates available

IMAGE CREATION TOOLS:
1. Canva.com
   - Create split images
   - Add text overlays
   - Professional templates
   - Free version available

2. Remove.bg
   - Remove backgrounds
   - Create clean cutouts

3. Photopea.com
   - Free Photoshop alternative
   - Edit and combine images

SEARCH STRATEGY:
1. Use specific search terms (provided for each tweet)
2. Combine 2-3 keywords for better results
3. Filter by "Free to use" or "Commercial use"
4. Download high resolution (at least 1080p)
5. Edit/crop to fit Twitter format (16:9 or 1:1)

TWITTER IMAGE SPECS:
- Recommended: 1200x675px (16:9)
- Square: 1200x1200px (1:1)
- Max file size: 5MB
- Formats: JPG, PNG, GIF

VIDEO SPECS:
- Max length: 2:20
- Recommended: 1080x1920 (vertical) or 1920x1080 (horizontal)
- Max file size: 512MB
- Formats: MP4, MOV
