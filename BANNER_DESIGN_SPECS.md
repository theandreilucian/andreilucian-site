## CUSTOMIZATION

### To Modify Text:
1. Open SVG file in text editor
2. Find `<text>` elements
3. Change text content between tags
4. Adjust font-size, font-weight, fill (color) attributes

### To Modify Colors:
1. Find color codes:
   - White: `#ffffff` or `fill="#ffffff"`
   - Cyan: `#00d9ff` or `fill="#00d9ff"`
   - Gray: `#b3b3b3` or `fill="#b3b3b3"`
2. Replace with your desired colors

### To Modify Icons:
- Icons are drawn using SVG paths
- Can be replaced with image files if preferred
- Or use icon libraries (Font Awesome, etc.)
