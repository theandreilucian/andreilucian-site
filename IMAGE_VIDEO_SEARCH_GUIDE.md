BEST FREE RESOURCES (NO ATTRIBUTION NEEDED)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. UNSPLASH.COM ⭐ BEST FOR PHOTOS
   - URL: https://unsplash.com
   - All images: 100% free, no attribution required
   - Quality: Professional, high-resolution
   - Search: Type keywords (e.g., "young entrepreneur", "tech office")
   - Download: Click image → Download button (top right)
   - Size: Usually 4000px+ wide (perfect for Twitter)

2. PEXELS.COM ⭐ BEST FOR VIDEOS + PHOTOS
   - URL: https://www.pexels.com
   - Photos + Videos: Both free
   - Quality: High-quality stock content
   - Search: Use search bar at top
   - Download: Click → Download button
   - Videos: Go to "Videos" tab for stock footage

3. PIXABAY.COM
   - URL: https://pixabay.com
   - Images + Videos: Free
   - Quality: Good variety
   - Search: Similar to above

HOW TO SEARCH EFFECTIVELY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Go to Unsplash.com or Pexels.com

STEP 2: Use these search term formulas:

For HOOK TWEET (split image):
- Left side: "young person" OR "college student" OR "teenager"
- Right side: "tech company" OR "government building" OR "corporate office"

For ORIGIN STORY:
- "small town" OR "hometown" OR "childhood"

For SKILL DEVELOPMENT:
- "cybersecurity" OR "coding screen" OR "hacking"
- "data network" OR "technology"

For TRANSITION:
- "office workspace" OR "corporate office"
- "university campus" OR "college"

For PROBLEM/REVEAL:
- "privacy violation" OR "surveillance"
- "data breach" OR "security"

For CLIMAX:
- "breaking news" OR "news broadcast"
- "stock market crash" OR "financial crisis"

For APPLICATION:
- "business speaker" OR "thought leader"
- "podcast" OR "professional speaking"

CREATING SPLIT IMAGES (LIKE KEN'S HOOK)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

METHOD 1: CANVA (EASIEST)
1. Go to canva.com (free account)
2. Click "Create a design" → "Custom size"
3. Enter: 2400px width × 1350px height (16:9 ratio)
4. Upload your 2 images
5. Drag images to fill left and right halves
6. Add subtle border/divider if needed
7. Download as JPG (high quality)

METHOD 2: PHOTOPEA (FREE PHOTOSHOP)
1. Go to photopea.com (works in browser)
2. File → New → 2400 × 1350px
3. Open your 2 images
4. Copy/paste each to left and right
5. Export as JPG

METHOD 3: REMOVE.BG + CANVA
1. Use remove.bg to remove backgrounds
2. Import both into Canva
3. Arrange side by side

- URL: https://www.pexels.com/videos/
- Search: "cybersecurity", "office", "news", etc.
- Download: Click video → Download
- Length: Choose 30-60 second clips

- Right-click video thumbnail → "Save image as"
- Use thumbnail as image (fair use)
- Or create your own thumbnail in Canva

OPTION 3: CREATE ANIMATED GRAPHICS
- Canva: Create graphic design
- Add animations
- Export as MP4 video
- Free version has basic animations

ADDING TEXT OVERLAYS TO VIDEOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CANVA METHOD:
1. Upload video to Canva
2. Click "Text" → Add text box
3. Type your text (e.g., "MARCH 15, 2023")
4. Style: Bold, large font, contrasting color
5. Position: Top center or bottom
6. Export as MP4

ALTERNATIVE: CAPCUT (FREE)
- Mobile app or web version
- Easy text overlay tool
- Free to use

TWITTER IMAGE SPECIFICATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RECOMMENDED SIZES:
- Landscape: 1200 × 675px (16:9 ratio)
- Square: 1200 × 1200px (1:1 ratio)
- Portrait: 675 × 1200px (9:16 ratio)

FILE FORMATS:
- Images: JPG or PNG
- Videos: MP4 or MOV

FILE SIZE LIMITS:
- Images: Max 5MB
- Videos: Max 512MB, Max 2:20 length

BEST PRACTICES:
- Use high resolution (at least 1920px wide)
- Compress if needed (use tinypng.com)
- Test on mobile before posting

WORKFLOW FOR CREATING THREAD IMAGES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

DAY 1: Gather Images
1. Open Unsplash.com
2. Search for each tweet's image needs
3. Download 2-3 options per tweet
4. Save to folder: "Thread Images"

DAY 2: Create Split Images
1. Open Canva.com
2. Create split images for hook tweet
3. Add text overlays if needed
4. Export all images

DAY 3: Find Videos
1. Open Pexels.com/videos
2. Search for video needs
3. Download 30-60 second clips
4. Add text overlays in Canva

DAY 4: Final Review
1. Check all images are correct size
2. Verify text is readable
3. Test on mobile view
4. Compress if needed (tinypng.com)

PRO TIPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. CONSISTENCY: Use similar style/color scheme across all images
2. CONTRAST: Make sure text overlays are readable
3. MOBILE: Always check how images look on phone
4. BACKUP: Download multiple options, pick best later
5. SPEED: Use Canva templates to save time
6. QUALITY: Always download highest resolution available
7. LEGAL: Stick to Unsplash/Pexels (100% free, no issues)
